# Сайт-визитка независимого партнёра ассоциации ВИЕДА (Whieda)

Одностраничный сайт на шести языках в одном самодостаточном файле `index.html` (HTML + CSS + JS внутри). Никаких сборщиков, зависимостей и картинок по ссылкам: из внешнего только шрифты Google Fonts.

## Языки

По умолчанию открывается **итальянский**. Переключатель — выпадающий список в шапке.

| Язык | Код | Прямая ссылка |
| --- | --- | --- |
| Italiano (по умолчанию) | `it` | `/viyeda-partner/` |
| English | `en` | `/viyeda-partner/?lang=en` |
| Русский | `ru` | `/viyeda-partner/?lang=ru` |
| Deutsch | `de` | `/viyeda-partner/?lang=de` |
| Français | `fr` | `/viyeda-partner/?lang=fr` |
| Español | `es` | `/viyeda-partner/?lang=es` |

Ссылку с `?lang=` можно отправлять сразу на нужном языке — страница откроется на нём. Выбор посетителя запоминается в его браузере, при следующем заходе язык сохранится. Язык браузера **не** определяется автоматически: по умолчанию всегда итальянский.

## Как открыть локально

Двойной клик по `index.html`. Переключатель языка работает и с диска.

## Что и где править

| Что менять | Где искать в `index.html` |
| --- | --- |
| Цвета | блок `:root` в самом начале `<style>` — все цвета переменными, с комментариями |
| Telegram, WhatsApp, телефон, e-mail | блок `CONTACTS` в начале `<script>` + закомментированные строки в футере |
| Ссылка регистрации по рекомендации | `CONTACTS.regUrl` в начале `<script>` (пока пустая) |
| **Итальянские** тексты | прямо в разметке, секции подписаны комментариями: HERO, VIEDA, PRODOTTI, PERCHÉ, DUE STRADE, CHI SONO, DOMANDE, CTA, FOOTER |
| Тексты остальных языков | объект `DICT` в конце `<script>`: `DICT.en`, `DICT.ru`, `DICT.de`, `DICT.fr`, `DICT.es` |
| Вопросы FAQ | секция `<section id="faq">` (итальянский) + пункты `qButtons` и `qBodies` в каждом языке |

### Как устроен перевод

Итальянский — язык самой разметки, он снимается со страницы при загрузке, поэтому дублировать его в словаре не нужно. Остальные языки лежат массивами строк **в том же порядке, в каком элементы идут на странице**: первый элемент `nav` — первая ссылка меню, третий `cardDd` — третий абзац в первой карточке и так далее.

Если добавляешь на страницу новый абзац или вопрос — добавь строку в тот же массив у каждого языка, иначе этот кусок останется итальянским. Порядок важнее текста: сдвинешь один пункт — переводы разъедутся.

Проверить себя можно так: открыть страницу, в консоли браузера прогнать переключение по всем языкам и посмотреть, не осталось ли итальянских фраз.

## Мелочи, которые легко принять за баг

- На экранах уже 560px кнопка «Написать» из шапки скрывается: рядом с выбором языка ей не хватает места при длинных словах. Главная кнопка при этом стоит сразу в первом экране.
- Форма ничего не отправляет на сервер: она собирает текст на текущем языке, копирует его в буфер и открывает чат в Telegram.

## Важно про тексты

В футере стоит дисклеймер: продукция не является лекарственным средством, сайт принадлежит независимому партнёру и не является официальным ресурсом компании, результаты в бизнесе индивидуальны. Его лучше не удалять — он есть во всех шести языках.

При правках не стоит добавлять: названия болезней, обещания лечения, конкретные суммы дохода и гарантии заработка.

## Публикация

Сайт опубликован через GitHub Pages из ветки `main`. Любой коммит в `main` автоматически обновляет живую версию через минуту-две.
