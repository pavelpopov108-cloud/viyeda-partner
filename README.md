# Сайт-визитка независимого партнёра ассоциации ВИЕДА (Whieda)

Одностраничный сайт в двух языковых версиях. Каждая версия — один самодостаточный файл (HTML + CSS + JS внутри). Никаких сборщиков, зависимостей и картинок по ссылкам: из внешнего только шрифты Google Fonts.

| Версия | Файл | Адрес |
| --- | --- | --- |
| Русская (основная) | `index.html` | `/viyeda-partner/` |
| Итальянская | `it/index.html` | `/viyeda-partner/it/` |

Переключатель языка — кнопка `IT / RU` в шапке, рядом с кнопкой «Написать». Обе версии связаны тегами `hreflang`, поэтому Google понимает, что это один сайт на двух языках, а не дубликат.

## Как открыть локально

Двойной клик по `index.html` — откроется в браузере. Переключатель языка работает и с диска.

## Важно: CSS продублирован

Стили лежат внутри каждого из двух файлов. Если меняешь цвет или отступ — правь в обоих файлах, иначе версии разъедутся. Тексты, наоборот, у каждой версии свои — это нормально.

Чтобы сделать итальянскую версию главной, скажи — переставлю файлы местами (это одна операция, вручную лучше не двигать, поедут ссылки `hreflang`).

## Что и где править

| Что менять | Где искать в `index.html` (и в `it/index.html`) |
| --- | --- |
| Цвета | блок `:root` в самом начале `<style>` — все цвета переменными, с комментариями |
| Telegram, WhatsApp, телефон, e-mail | блок `CONTACTS` в начале `<script>` + закомментированные строки в футере |
| Ссылка регистрации по рекомендации | `CONTACTS.regUrl` в начале `<script>` (пока пустая) |
| Тексты | прямо в разметке, секции подписаны комментариями: HERO, ЧТО ТАКОЕ ВИЕДА, ПРОДУКЦИЯ, ПОЧЕМУ, ДВА ПУТИ, ОБО МНЕ, FAQ, CTA, ФУТЕР |
| Вопросы FAQ | секция `<section id="faq">`, каждый вопрос — блок `<div class="q">` |

## Важно про тексты

В футере стоит дисклеймер: продукция не является лекарственным средством, сайт принадлежит независимому партнёру и не является официальным ресурсом компании, результаты в бизнесе индивидуальны. Его лучше не удалять.

При правках не стоит добавлять: названия болезней, обещания лечения, конкретные суммы дохода и гарантии заработка.

## Публикация

Сайт опубликован через GitHub Pages из ветки `main`. Любой коммит в `main` автоматически обновляет живую версию через минуту-две.
